# Support

We're here to help! Here's how to get support for the Duplicate Finding Tool.

## Getting Help

### GitHub Discussions (Recommended for Questions)

Use [GitHub Discussions](https://github.com/tim-dickey/duplicate-finding-tool/discussions) for:
- General questions about usage
- How-to questions
- Best practices and tips
- Feature discussions

This is the best place for community-driven answers and conversations.

### GitHub Issues (For Bugs and Feature Requests)

Use [GitHub Issues](https://github.com/tim-dickey/duplicate-finding-tool/issues) for:
- **Confirmed bugs** - reproducible issues with the code
- **Feature requests** - proposals for new functionality
- Please use the provided templates

⚠️ **Note**: General usage questions should go to Discussions, not Issues.

## Documentation

Before asking, please check:
- [README.md](README.md) - Quick start and overview
- [docs/](docs/) folder - Detailed documentation
- Existing Discussions and closed Issues

## What to Expect

- We're all volunteers contributing our time
- Response times vary based on availability
- We'll do our best to help, but support is best-effort
- For commercial support needs, please inquire directly

## Contributing to Support

You can also help by:
- Answering questions in Discussions
- Improving documentation
- Creating examples and tutorials
- Testing and reporting bugs

Thank you for being part of our community!
